# Career Quest — альтернативный frontend-preview

Основной командный интерфейс сохранён в `frontend/` из origin/main.
Быстро созданный в этой сессии вариант сохранён отдельно в `frontend-preview/`.
Инструкция основного интерфейса: [frontend/README.md](../frontend/README.md).

React + TypeScript + Vite. Интерфейс использует реальный `/api`, без mock-данных
и без доступа к OpenAI из браузера. JWT хранится только в памяти; после обновления
страницы нужно войти заново. Пароль демо-аккаунтов берётся из серверного DEMO_PASSWORD.

Экраны: вход; план развития; навыки и профиль; история; HR-обзор; импорт JSON/CSV
для admin. Complete подтверждается пользователем; новый профиль берётся из ответа
сервера, затем рекомендации запрашиваются отдельно. Устаревшие ответы игнорируются.

Локально из `frontend-preview`: `npm ci`, затем `npm run dev`.
Адрес http://127.0.0.1:5174, proxy `/api` на backend http://127.0.0.1:8765.
Для production-сборки: `npm run build`; для её раздачи backend запустить
с `STATIC_DIR=frontend-preview/dist` из корня проекта. Docker по умолчанию
собирает основной командный `frontend`, а не этот альтернативный вариант.

Браузерный smoke: `npx playwright test` при работающем сервере на 8765,
раздающем сборку preview, установленном Microsoft Edge и DEMO_PASSWORD в окружении тестового процесса.
Проверяет вход, настоящий профиль, отсутствие HR для employee и выход.

До объединения веток сборка preview, браузерные вход/профиль/выход и загрузка
реальных рекомендаций проверены. После объединения новые тесты не запускались
по просьбе пользователя; основной frontend напарника в этой сессии не проверялся.

Ограничения быстрого прототипа: RU основной, переключатель KK/EN переводит
навигацию и основные действия и передаёт lang серверу; полная локализация
пояснений и HR ещё не выполнена. Python/Docker-проверки описаны в docs/backend.md.
